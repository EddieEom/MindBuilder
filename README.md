
# MindBuilder

## 프로젝트 소개

MindBuilder는 AI 시대의 Human Operating System(Human OS)을 구축하기 위한 AI 기반 사고 분석 플랫폼입니다.

이 프로젝트는 감정을 기록하는 서비스가 아니라,

사용자의 사고 데이터를 장기적으로 수집하고 분석하여

- 사고 패턴
- 성장 방향
- Identity
- Life Map
- Human Operating System

을 구축하는 것을 목표로 합니다.


# 프로젝트 철학

```
## 프로젝트 철학

우리는 감정을 수집하지 않습니다.

우리는 사고 데이터를 수집합니다.

우리는 사람을 치료하지 않습니다.

우리는 사고 구조를 발견합니다.

우리는 정답을 제공하지 않습니다.

우리는 사용자가 스스로 답을 찾도록 돕습니다.

우리는 Human Operating System을 구축합니다.
```
