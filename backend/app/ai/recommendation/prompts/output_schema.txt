Return ONLY valid JSON.

The response MUST be a single JSON object.

Required structure:

{
    "recommendations": [
        {
            "title": "실제 추천 제목",
            "description": "실제 추천 설명",
            "priority": 1,
            "actions": [
                {
                    "title": "실제 실행 행동",
                    "description": "실제 행동 설명"
                }
            ]
        }
    ],
    "confidence": 0.0
}

OUTPUT REQUIREMENTS

recommendations

- Must be an array.
- May contain zero or more recommendations.
- Every recommendation MUST be based on the supplied Pattern, Growth, Identity, and LifeMap analyses.
- Do NOT copy this structure literally.
- Replace every example value with actual generated Korean content.

title

- Must contain the actual Korean recommendation.
- Must NOT be "string".
- Must NOT be empty.
- Must NOT be a placeholder.
- Must be concise.

description

- Must contain the actual Korean explanation of the recommendation.
- Must be exactly one concrete sentence.
- Must NOT be "string".
- Must NOT be empty.
- Must NOT be a placeholder.

priority

- Must be an integer.
- Allowed values are only 1, 2, or 3.

actions

- Must contain between 1 and 3 actions.
- Every action MUST be concrete and executable.
- Every action MUST represent the smallest meaningful step toward the recommendation.

action.title

- Must contain actual Korean content.
- Must NOT be "string".
- Must NOT be empty.
- Must NOT be a placeholder.

action.description

- Must explain the concrete action.
- Must contain actual Korean content.
- Must NOT be "string".
- Must NOT be empty.
- Must NOT be a placeholder.

confidence

- Must be a number between 0.0 and 1.0.
- Do NOT always output 1.0.
- Reflect how strongly the recommendations match Growth, Identity, LifeMap, and Pattern.

PLACEHOLDER PROHIBITION

Never output the literal value:

"string"

Never output:

"example"

"test"

"<title>"

"<description>"

"<action>"

"<value>"

If the evidence is insufficient to create a grounded recommendation, return:

{
    "recommendations": [],
    "confidence": 0.0
}

FINAL OUTPUT RULE

Return ONLY the JSON object.

Do NOT output Markdown.
